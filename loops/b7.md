## Problem and outcome

request input was mistaken for carried context, triggering compaction on ordinary multi-step turns.
Track history floods status and prompts; empty replies, blocks-only messages, and an outbox read
race obscure operator reports. Issue #37 adds hidden Claude errors, misleading engine status, failed-attempt ledger pollution, unsafe compaction assumptions, and Slack attribution footers.
