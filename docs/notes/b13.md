# b13: truthful engine diagnostics

## What changed
Status now compares configured account/model with the recorded last runner, lists ordered attempts, counts consecutive off-configured turns and reports account failures and reset times. Display normalization distinguishes session collisions from usage and credit exhaustion. Existing runtime behavior and non-engine status lines remain unchanged for valid logs. Malformed turn logs yield an unavailable compaction diagnostic rather than crashing status.

## Evidence
Frozen acceptance: [b13.acceptance] PASS. Full-suite target: 441 passed (433 existing tests and eight added regressions); the frozen exit verifies this count against the executed suite before permitting PASS. Eight added regressions cover missing/malformed logs, exclusive overlapping attribution, persistent and active/inactive fallback line preservation. The live-log candidate preview showed both session collisions and the actual Codex runner in under one second; deployment evidence remains pending. Frozen acceptance covers sanitized recorded attempts, repeated turns, usage/credits, reset conversion, recovery, model-only mismatch, ordering and reason truncation.

## Open questions
Attempts have no turn IDs; association uses second-resolution timestamps and completed intervals, with exclusive ownership at the next turn start. New timestamps use fixed PDT; old status line formats remain preserved. Runtime recovery and fallback policy are separate work. Build PASS does not imply deployment closure.
