# b13: corrected status evidence

## What changed
Usage rule (founder amendment 2026-10-15, loops/b13.md): `usage: ok` only when the account's latest recorded attempt succeeded; `usage: limit at <time>` when a credits/usage-limit row follows the last success (a later success resets it, later non-usage failures do not); otherwise `usage: unknown (no successful call since <last ok>)`, or `(no successful call recorded)` for an account that never succeeded; no attempts stay `usage: unknown`. The `(API not reached since ...)` wording is retired: a timeout, a supervisor death or a session collision proves nothing about quota. Only the usage branch of `_status_engine_lines` changed; every other runtime definition is AST-identical to BASE_REF 8cb37d84f7fca5d56ae7a8cf28644c5edd759a15. Earlier b13 work (account failure onset, last success, preceding different-class failure, Pacific timestamps, stale context suffix) is unchanged.
